📘 markdown / github / documentação

Citações coloridas no GitHub, direto do Markdown.

Os Alerts são blocos de destaque oficiais do GitHub — quatro variações de citação que deixam READMEs, issues e pull requests mais fáceis de ler, sem sair do Markdown puro.

O que são // conceito

Alerts são blocos especiais baseados em citação (>) que o GitHub renderiza com cor, ícone e título próprios — parecidos com as caixas informativas de documentações técnicas modernas.

> [!TIP]
> Seu texto aqui

Note 01

Uma observação complementar ou explicação extra — não muda o que o leitor precisa fazer, só ajuda a entender melhor.

código
> [!NOTE]
> Esta funcionalidade funciona apenas no GitHub Markdown.
resultado
Note

Esta funcionalidade funciona apenas no GitHub Markdown.

Tip 02

Sugestões, boas práticas ou atalhos úteis para quem está lendo.

código
> [!TIP]
> Utilize nomes de variáveis claros para melhorar a leitura do código.
resultado
Tip

Utilize nomes de variáveis claros para melhorar a leitura do código.

Warning 03

Algo que pode causar erro, problema técnico ou comportamento inesperado.

código
> [!WARNING]
> Não execute este comando em ambiente de produção.
resultado
Warning

Não execute este comando em ambiente de produção.

Important 04

Algo essencial que o leitor precisa saber antes de continuar.

código
> [!IMPORTANT]
> Certifique-se de instalar todas as dependências antes de executar o projeto.
resultado
Important

Certifique-se de instalar todas as dependências antes de executar o projeto.

Regras importantes

  • Funciona apenas no GitHub — não em todo Markdown.
  • Deve começar com > (citação).
  • O identificador precisa estar em maiúsculo, entre colchetes: [!TIP].
  • O texto do alerta fica na linha abaixo, também com >.
exemplo incorreto
[!TIP] Texto aqui

Não funciona — falta o símbolo > no início.

Dica extra

Emojis funcionam normalmente dentro de qualquer alert.

Tip

🚀 Automatize tarefas repetitivas sempre que possível.
